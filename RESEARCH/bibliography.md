# Bibliography

## Status and citation policy

All repository material was retrieved with GitHub CLI on 2026-10-06. The constraint to fetch all data through GitHub CLI prevents direct retrieval of journal full text and official vendor documentation. The records below are therefore a **working, source-linked bibliography**: verify title, population, methods, result and version against the primary paper/official page before any scientific claim is promoted or any technical contract is implemented.

2. Van Dongen HPA, Maislin G, Mullington JM, Dinges DF.
